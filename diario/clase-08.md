# Clase 8 · Primera visualización

**Qué se intentó.** Pasar de la tabla al gráfico: partes de un gráfico, ejes, títulos. El script de carga, transformación y visualización pasó por tres versiones (V1, V2, V3).

**Qué falló.** Guardar las versiones como archivos distintos (`V2`, `V3`) en vez de usar Git hizo difícil saber qué había cambiado en cada una.

**Qué se decidió.** Una sola versión del archivo y los cambios en *commits*. El título del gráfico tiene que decir lo que se ve.
