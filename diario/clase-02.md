# Clase 2 · El proceso generador de datos

**Qué se intentó.** Pensar de dónde viene un dato antes de analizarlo (el DGP: el dato se construye midiendo) e instalar pandas para los ejemplos.

**Qué falló.** `pip install pandas` no funcionaba: Windows no reconocía `pip` (ver `errores/01`).

**Qué se decidió.** Usar siempre `py -m pip install ...`. Y antes de abrir un archivo, preguntarse quién lo midió, cómo y qué quedó afuera.
