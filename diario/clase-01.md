# Clase 1 · Git, GitHub y un análisis que otro pueda repetir

**Qué se intentó.** Crear la cuenta de GitHub, clonar el repositorio del curso y correr el primer ejemplo (`ejemplo_pinguinos.py`, diez filas de los pingüinos de Palmer escritas a mano).

**Qué falló.** Los pasos de Git (guardar, *commit*, *push*) no son automáticos: un archivo guardado en la PC no está en GitHub hasta hacer *push*.

**Qué se decidió.** Trabajar siempre dentro de una carpeta del repositorio y confirmar los cambios con un mensaje que diga qué se hizo.
